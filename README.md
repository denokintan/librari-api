# Library API - Top Borrowers

## Endpoint
GET /api/loans/top-borrowers

## Deskripsi
Endpoint untuk menampilkan 3 peminjam teratas berdasarkan jumlah transaksi.

## Teknologi
- Node.js
- Vercel
- Neon PostgreSQL

## Cara Menjalankan
1. Install dependencies
   npm install

2. Jalankan di Vercel
   vercel
